Externí, interní a inline styly CSS

Vzhled HTML dokumentu (barvy, písmo, rozvržení) se definuje pomocí jazyka CSS (Cascading Style Sheets). Existují tři základní způsoby, jak CSS k HTML prvkům připojit. Níže jsou vysvětleny tagy a atributy, které k tomu slouží.

1. Externí styly (Tag <link>)

Nejpoužívanější a nejvhodnější způsob stylování rozsáhlejších webů je oddělení grafiky od struktury do samostatného souboru s příponou .css. K propojení tohoto souboru s HTML stránkou slouží nepárový tag <link>.

Tento tag se umísťuje do neviditelné hlavičky dokumentu (tag <head>). Využívá atribut rel="stylesheet", kterým prohlížeči říká, že připojuje kaskádové styly, a atribut href="moje-styly.css", který obsahuje cestu (odkaz) k danému CSS souboru.

2. Interní styly (Tag <style>)

Pokud chceme definovat styly pouze pro jednu konkrétní stránku, můžeme využít interní zápis. K tomu slouží párový tag <style>, který se rovněž umísťuje do hlavičky (<head>). Z této ukázky byl odstraněn a přesunut právě do externího souboru.

3. Inline styly (Atribut style)

Třetím způsobem je takzvané inline stylování (přímý zápis). To se provádí pomocí atributu style přímo u konkrétní otevírací HTML značky, kterou chceme upravit.

Tento konkrétní odstavec využívá inline styl pro nastavení světle modrého pozadí a tenkého modrého rámečku. Tento zápis má z hlediska pravidel CSS (kaskády) nejvyšší prioritu a přebije případná nastavení z externího souboru.

Ukázka kódu (Tag <pre>)

Pro zobrazení zdrojového kódu přímo na stránce bez toho, aby jej prohlížeč vykonal, se používá tag <pre> (preformatted text). Ten zachovává mezery i zalomení řádků přesně tak, jak byly napsány: 

/* Ukázka z našeho nového souboru moje-styly.css */
body {
    font-family: Arial, sans-serif;
    background-color: #f4f4f9;
}
p {
    line-height: 1.6;
}
