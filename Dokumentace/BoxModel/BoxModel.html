CSS Box Model

1. Složení Box Modelu

Každý prvek na webové stránce je z pohledu CSS obdélníková "krabice". Skládá se ze čtyř základních vrstev. Pro názornost jsou v ukázce níže tyto vrstvy vizuálně rozloženy do sebe a barevně odlišeny:

Margin (Vnější okraj - neviditelný, odtlačuje okolní prvky)
Border (Rámeček - ohraničuje prvek)
Padding (Vnitřní okraj - prostor mezi rámečkem a obsahem)
Content (Samotný obsah - text, obrázek, video...)

2. Základní styly rámečků (Border Style)

Vlastnost border je složena z tloušťky, barvy a stylu. Níže jsou ukázky čtyř nejčastějších stylů rámečků aplikovaných pomocí samostatných tříd.

Solid (Plný)
Dashed (Čárkovaný)
Dotted (Tečkovaný)
Double (Dvojitý)

3. Alternativní chování (Box-Sizing)

Oba obdélníky níže mají v CSS definovanou šířku width: 100%, odsazení padding: 20px a tlustý rámeček border: 15px. Chovají se ale úplně jinak díky vlastnosti box-sizing.

Standardní model (box-sizing: content-box)
Šířka 100 % platí jen pro modrý "Content". Padding a Border se přičítají k této šířce navíc. Výsledkem je, že obdélník přetéká mimo obrazovku a vytváří horizontální posuvník.
Alternativní model (box-sizing: border-box)
Šířka 100 % platí pro celý box včetně rámečku a vnitřního odsazení. Padding i Border se ukrajují směrem dovnitř. Obdélník se perfektně vejde do vymezeného prostoru.
