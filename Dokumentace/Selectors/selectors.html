Kompletní přehled CSS Selektorů

Značky, Třídy a ID Kontext a Společné Vnořené a Sourozenecké

1. Značky, Třídy a Identifikátory

Selektor značky: Definuje styl přímo pro HTML tagy (např. body, h1). Změní vše plošně.

Selektor třídy (Class): Začíná tečkou (.sekce-obsahu). Můžete jej libovolně opakovat a kombinovat.

Selektor identifikátoru (ID): Začíná mřížkou (#unikatni-upozorneni). Každé ID smí být v HTML souboru použito pouze jednou. Zde je použito pro žlutý varovný blok.

2. Společné a kontextuální definice

Společná definice (Seskupení): Používá čárku. Umožňuje sdílet styl pro více prvků (h1, h2, h3 { color: blue; }).

Kontextuální definice (Mezera): Vybírá prvky podle jejich umístění. Například .navigace a změní vzhled pouze těm odkazům, které se nacházejí někde uvnitř navigačního pruhu, nikoliv odkazům v běžném textu.

3. Vnořené a sourozenecké selektory

Přímý potomek (znak >)

  • Tato položka je přímým potomkem (má zelený pruh).
    • Tato položka už přímým potomkem .seznam-potomku není (leží hlouběji), pruh tedy nedostane. Kdybychom použili kontextuální zápis (mezeru), zezelenala by také.

Přímý sourozenec (znak +)

Tento první odstavec leží těsně za nadpisem (h3 + p), proto je podbarven žlutě.

Tento druhý odstavec už bezprostředně za nadpisem nenásleduje, proto zůstává bez barvy.

Obecný sourozenec (znak ~)

Běžný text před klíčovým slovem. Klíčové slovo! Tento text je červený (leží za klíčovým slovem). Tento text je také červený.
