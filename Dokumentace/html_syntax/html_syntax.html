1. Základní syntaxe HTML

HTML (HyperText Markup Language) není programovací jazyk, ale značkovací jazyk. Slouží k definici struktury webové stránky pomocí takzvaných tagů (značek). Tagy se zapisují do lomených závorek.

Obecný zápis HTML elementu:

<nazev-tagu>Zde je nějaký viditelný obsah</nazev-tagu>

2. Párové a nepárové tagy

HTML tagy rozdělujeme na dvě základní skupiny podle toho, zda obalují nějaký textový obsah, nebo existují samy o sobě.

  • Párové tagy: Skládají se z otevírací a ukončovací značky. Ukončovací značka má navíc lomítko. Tímto způsobem se tvoří nadpisy, odstavce nebo odkazy.
    Ukázka: <p>Toto je odstavec.</p>
  • Nepárové tagy (prázdné elementy): Nemají žádný obsah mezi značkami, a proto nemají ukončovací tag. Slouží k vložení konkrétního prvku přímo na dané místo (např. obrázek, zalomení řádku, vodorovná čára).
    Ukázka: <br> (zalomení řádku) nebo <img src="obrazek.jpg">

3. Atributy tagů (Argumenty)

Atributy poskytují HTML tagům dodatečné informace a vlastnosti (například kam má odkaz směřovat, jakou má mít prvek třídu nebo cestu k obrázku).

  • Atributy se píší vždy a pouze do otevírací značky (nebo do nepárové značky).
  • Skládají se z názvu atributu a jeho hodnoty zapsané v uvozovkách: nazev="hodnota".
  • Více atributů v jednom tagu se odděluje běžnou mezerou.

Ukázka tagu s atributy:


<a href="https://www.w3.org" target="_blank">Klikni zde</a>


<img src="logo.png" alt="Logo naší společnosti">
