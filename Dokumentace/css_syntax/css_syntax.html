Základní syntaxe a Kaskádování

1. Základní syntaxe

Každé pravidlo CSS se skládá ze selektoru (určuje, jaký prvek na stránce formátujeme) a bloku deklarací ohraničeného složenými závorkami[cite: 1]. Uvnitř bloku definujeme vlastnost (co měníme) a její hodnotu (jak to má vypadat). Každý zápis vlastnosti a hodnoty je oddělen dvojtečkou a musí končit středníkem.

Zdrojový kód (rozpad syntaxe):

/* 1. Obecný teoretický vzorec */
selektor {
    vlastnost: hodnota;
}

/* 2. Konkrétní příklad (formátování nadpisu h1) */
h1 {
    color: blue;          /* Vlastnost "color", hodnota "blue" */
    text-align: center;   /* Vlastnost "text-align", hodnota "center" */
}

2. Zkrácený zápis (Shorthand)

Některé vlastnosti slučují více parametrů. Níže formátovaný blok využívá shorthand pro rámeček, vnější okraj a vnitřní odsazení.

Blok formátovaný zkráceným zápisem.

Zdrojový kód (pseudo-kód) k bloku výše:

.shorthand-box {
    /* 1. Tloušťka, 2. Styl, 3. Barva */
    border: 3px dashed #0056b3;
    
    /* 1. Svisle (nahoře/dole), 2. Vodorovně (vpravo/vlevo) */
    margin: 15px 0;
    
    /* Hodnoty po směru hodinových ručiček: Nahoře, Vpravo, Dole, Vlevo */
    padding: 10px 20px 30px 40px; 
}

3. Priorita a dědičnost (Kaskádování)

Styly se aplikují v určitém pořadí (kaskáda) a ty specifičtější přepisují ty obecnější[cite: 1]. Rozhoduje síla selektoru (Inline styl > Třída > Tag) a pořadí v kódu.

Odstavec 1: Formátován přes obecný tag "p". Text je šedý.

Odstavec 2: Využívá třídu ".kaskada-trida". Třída je silnější než tag, text je modrý.

Odstavec 3: Má obě třídy. Třída ".kaskada-pozdejsi" je v hlavičce napsána níže, proto vyhrává červená barva.

Odstavec 4: Využívá atribut style přímo v HTML. Inline styl má absolutní přednost, text je zelený.

CSS pravidla určující chování odstavců:

/* 1. Nejnižší síla: Tag (Odstavec 1) */
.kaskada-box p {
    color: #888888;
}

/* 2. Vyšší síla: Třída (Odstavec 2) */
.kaskada-trida {
    color: #0056b3;
}

/* 3. Stejná síla jako předchozí, ale napsáno níže (Odstavec 3) */
.kaskada-pozdejsi {
    color: #d9534f;
}

/* 4. Odstavec 4 v HTML vypadá takto: (Nejvyšší síla - Inline) */
/* <p class="kaskada-trida" style="color: #28a745;">...</p> */
